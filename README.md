# how_long
یک برنامه کوچک فقط برای اینکه  ببینه ویدیو های درون پوشه مجموعا چند دقیقه‌اند!

.مخصوص دوره های آموزشی طولانی!!!


## نصب
در ترمینال با`python>=3.11` اجرا کنید:
```
pip install -e .
```
سپس در تمام محیط ترمینا ل با دستور `how-long` در دسترس خواهد بود.

"-----"

## دستورات
### جستوجو فقط در پوشه کنونی
``` $ how-long```
### جستوجو در یک پوشه بخصوص
``` $ how-long -f foo
$ how-long --folder foo
```

### جستوجو در پوشه کنونی تمامی زیرپوشه‌ها
```
$ how-long -s
$ how long --subdirs
```
